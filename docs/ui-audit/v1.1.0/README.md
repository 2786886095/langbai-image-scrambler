# v1.1.0 离屏 UI 截图审查

本轮继续使用 Flutter Widget Test 离屏渲染，没有启动或控制本机桌面应用。所有视口使用 `tester.view.physicalSize` 和 `devicePixelRatio = 1` 固定真实逻辑尺寸。

## 结论

- 21 个关键界面/状态全部通过黄金图渲染与逐像素复核。
- 新增“导出记录”入口在 Windows 侧边栏和 Android 顶部操作区均清晰可见。
- 撤回记录弹窗按记录数量自适应高度，Windows/Android 均无过量留白和内容遮挡。
- 设置页新增“撤回记录”和“批量性能”，默认值分别为 7 天与自动并发（最多 4 张）。
- 多文件夹队列按文件夹显示名称和数量，默认折叠，展开入口明确。
- 360×640 小屏、390×844、844×390 横屏、130% 字体、深浅主题和简繁体均无布局溢出。

## 关联验证

- 57 项测试通过。
- `flutter analyze`：0 问题。
- 并发工作者测试确认手动 4 并发会同时运行 4 个处理任务。
