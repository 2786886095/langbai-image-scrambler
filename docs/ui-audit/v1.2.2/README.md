# v1.2.2 离屏 UI 截图审查

审查日期：2026-08-09。

本轮继续使用 Flutter 测试离屏渲染，不启动 Windows 桌面窗口，也不调用用户桌面。界面由固定字体、固定设备尺寸和确定性数据生成，再执行黄金图复测与人工视觉检查。

## 覆盖范围

- Windows 1440×900：新增 TXT 压缩输出完整设置，包含 ZIP/7Z、三种打包方式、密码选择与密码管理入口。
- Android 360×640：新增 TXT 压缩窄屏布局，验证打包方式自动换行、下拉框宽度和触控区域。
- 原有 Windows、Android 竖屏/横屏、1.3 倍文字、简体中文与繁体中文界面全部回归。

共 33 张黄金图，截图复测 `33/33` 通过；其余 Flutter 功能测试 `55/55` 通过，合计 `88/88`。

## 人工视觉检查结论

- TXT 压缩设置在 Windows 与待处理队列形成清晰双栏，不挤压导入区或主操作按钮。
- 360 像素 Android 窄屏下“每个文件夹”“每个文件”“全部合并”按空间自然换行，没有横向溢出或文字裁切。
- ZIP/7Z 分段按钮、压缩密码下拉框和“管理密码”入口均保持完整可见与标准触控高度。
- 压缩关闭时设置收起为紧凑卡片；开启时展开详情，层级和现有图片压缩设置一致。
- 新增说明明确同时支持图片与 TXT，未出现含义冲突或重复命名。

关键截图位于 `docs/screenshots/text-compression-*.png`，完整测试基准位于 `test/goldens/`。
