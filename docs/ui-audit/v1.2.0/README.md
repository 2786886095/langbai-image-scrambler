# v1.2.0 离屏 UI 截图审查

审查日期：2026-08-08。

本轮只使用 Flutter 测试渲染，不启动 Windows 桌面窗口，也不调用用户桌面。全部界面由固定字体、固定设备尺寸和确定性测试数据生成；随后执行像素级黄金图复测。

## 覆盖范围

- Windows 1440×900：主工作台、算法选择器、TXT 工作区、设置页顶部/底部、密码保护、导出记录、多文件夹折叠队列、压缩输出。
- Android 390×844：主工作台、算法选择器、TXT 工作区、设置页顶部/底部、图片还原、浅色主题、导出记录、多文件夹折叠队列、分享导入、压缩输出、压缩密码库。
- Android 360×640：主工作台、分享导入、压缩输出。
- Android 844×390：横屏工作台。
- Android 390×844、文字缩放 1.3：大字体工作台。
- 简体中文与繁体中文关键工作区。

共 27 张黄金图，复测结果 `27/27` 通过；全项目 Flutter 测试合计 `72/72` 通过。

## 人工视觉检查结论

- 算法选择器保持卡片式层级，不再出现难以浏览的长列表。
- 压缩设置在 360 像素宽度自动换行，ZIP/7Z、三种打包方式、密码选择与管理按钮均无截断。
- 密码库使用全高底部面板，列表和底部主按钮分区明确，编辑/删除触控目标不小于 48 像素。
- 分享导入在 360×640 下仍可滚动，底部主操作固定可达；压缩包密码不会挤压来源列表。
- Windows 双栏工作台、Android 单栏工作台均无横向溢出、组件重叠、文字越界或不可达操作。
- 深色、浅色、简体、繁体与 1.3 倍字体均保持可读对比度和稳定布局。
