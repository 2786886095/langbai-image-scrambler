# v1.0.1 离屏 UI 截图审查

本次审查使用 Flutter Widget Test 离屏渲染完成，没有启动或控制本机桌面应用。测试视口通过 `tester.view.physicalSize` 与 `devicePixelRatio = 1` 固定，确保应用实际接收到对应逻辑尺寸。

## 审查结论

- 17 个关键界面/状态均成功渲染，无 Flutter overflow、布局断言、遮挡或横向滚动问题。
- Windows 1440×900 正确进入桌面断点并显示侧边栏与双栏工作区。
- Android 390×844、360×640、844×390 横屏均保持可滚动、无固定操作区遮挡。
- 算法选择器在 Windows 完整显示 7 种算法；Android 使用单列触控卡片并完整显示末项。
- 设置弹窗顶部/底部、图片生成/还原、密码输入、TXT 工作区、深色/浅色、简体/繁体均已覆盖。
- Android 130% 字体缩放无文本溢出；内容可继续纵向滚动。
- 浅色主题次要文本的不透明度已提高到 0.65；按当前色板计算，正文对比度不低于约 4.86:1。

## 本轮发现并修复

1. **设置项涟漪层级**：`SwitchListTile` 原先位于带背景的 `DecoratedBox` 内，点击涟漪可能被遮住；改为带 shape 的 `Material` 容器。
2. **截图视口错误**：旧测试只改变截图表面尺寸，`MediaQuery` 仍收到 800×600；改为 Flutter 3.44 的 `tester.view` API，并加入实际 Scaffold/MediaQuery 尺寸断言。
3. **算法末项截断**：Windows 弹窗上限由 660 提升至 760，Android 底部面板由 84% 提升至 92%。
4. **繁体截图字体**：离屏测试补载 `NotoSansCJKTC`，确认繁体中文无缺字方框。
5. **浅色文本对比度**：小字号次要文本统一提高到 0.65 不透明度。
