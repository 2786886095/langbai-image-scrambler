# v1.2.3 离屏 UI 截图审查

审查日期：2026-08-09。

本轮继续使用 Flutter Golden Test 离屏渲染，不启动 Windows 桌面窗口，也不调用用户桌面。固定字体、窗口尺寸、主题和测试数据生成截图后，执行像素级复测与人工视觉检查。

## 覆盖范围

- Windows 1440×900：更新可用横幅、“立即更新”按钮、设置页 GitHub 项目主页入口、待继续导出状态。
- Android 390×844：更新下载进度、待继续导出状态、设置页更新入口。
- Android 360×640、横屏和 1.3 倍字体，以及既有图片、TXT、压缩、密码库、分享导入、历史记录和算法选择界面全部回归。

共 37 张 Golden 截图，复测 `37/37` 通过；Flutter 功能测试 `60/60` 通过。

## 人工视觉检查结论

- 更新横幅在桌面和手机宽度下均保持清晰层级，没有横向溢出、文字裁切或布局跳动。
- 下载进度同时使用进度条、百分比与文字状态，不只依赖颜色表达。
- “立即更新”在处理任务或存在待导出缓存时进入明确禁用状态，避免退出安装造成工作丢失。
- 设置页按钮使用自适应换行；Android 窄屏下“立即检查”和“GitHub 项目主页”保持完整 48dp 以上触控高度。
- “继续导出”使用独立上传图标和状态说明，保留结果的含义明确，Windows 与 Android 视觉一致。

关键截图位于 `docs/screenshots/v1.2.3/`，完整测试基准位于 `test/goldens/`。
