# v1.2.1 离屏 UI 截图审查

审查日期：2026-08-09。

本轮只使用 Flutter 测试渲染，不启动 Windows 桌面窗口，也不调用用户桌面。界面由固定字体、固定设备尺寸和确定性测试数据生成，再执行黄金图复测与人工视觉检查。

## 覆盖范围

- Windows 1440×900：主工作台、算法选择器、剪贴板/TXT 工作区、设置、密码保护、导出历史、多文件夹队列、压缩输出。
- Android 390×844：主工作台、剪贴板/TXT 工作区顶部与下部、设置、图片还原、浅色主题、导出历史、多文件夹队列、分享导入、压缩输出、密码库。
- Android 360×640：主工作台、剪贴板/TXT 工作区下部、分享导入、压缩输出。
- Android 844×390：普通工作台与 TXT 工作区横屏。
- Android 390×844、文字缩放 1.3：普通工作台与 TXT 工作区大字体。
- 简体中文与繁体中文关键工作区。

共 31 张黄金图，截图复测 `31/31` 通过；其余 Flutter 功能测试 `51/51` 通过，合计 `82/82`。

## 人工视觉检查结论

- 剪贴板输入与输出在 Windows 使用双栏，在 Android 竖屏自动改为单栏；按钮、标签和错误区域均保持清晰层级。
- 360 像素窄屏、横屏和 1.3 倍字体下没有横向溢出、组件重叠或不可达操作。
- 粘贴、清空、复制与处理按钮间距不小于 8 像素；图标按钮保留标准 Material 触控区域与提示文本。
- 导出历史的“打开输出位置”和“撤回导出”在桌面与手机端均可换行排列，不挤压路径信息。
- 深色、浅色、简体、繁体均保持既有主题层级与可读对比度。

关键截图位于 `docs/screenshots/`，完整测试基准位于 `test/goldens/`。
