# Langbai 图片混淆 v1.2.0

## 新功能

- Android 支持从系统分享面板导入文件、多个文件、文件夹及 ZIP、7Z、RAR。
- 加密压缩包可在导入时输入密码；图片与 TXT 自动分类，保留压缩包内部目录结构。
- 图片混淆支持可选 ZIP/7Z 输出，可按文件夹、按文件或全部合并打包。
- 压缩模式最终只导出压缩包，任务临时 PNG 在导出后清理。
- 同一批次所有压缩包统一使用一项密码；支持多个具名密码的安全保存、编辑、删除与切换。
- 修正安装测试隔离流程，避免测试卸载影响正式桌面快捷方式；首次安装默认勾选创建快捷方式。

## 下载

- Windows 安装版：`Langbai-Image-Scrambler-Setup-v1.2.0.exe`
- Android：`Langbai-Image-Scrambler-v1.2.0-android.apk`
- Windows 免安装版：`Langbai-Image-Scrambler-v1.2.0-windows-portable.zip`
- 校验文件：`SHA256SUMS.txt`

Android 包继续使用 `com.langbai.imagescrambler` 和原正式签名，可覆盖升级 v1.1.0。
