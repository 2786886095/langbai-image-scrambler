# Langbai 图片混淆 v1.0.1

本版本改善算法选择体验，并新增小说 TXT 标准 Base64 批量转码与精确还原。

## 新增与改进

- 顶部新增“图片混淆 / 小说 TXT”工作区切换。
- TXT 支持多选、文件夹递归导入和 Windows 拖放。
- TXT 按原始字节执行标准 Base64 转码，输出 `原文件名_混淆.txt`。
- TXT 还原时恢复原始字节，输出 `原文件名_还原.txt`；原编码与换行符保持不变。
- 文件夹任务以原文件夹名作为导出根目录，并保留内部子目录结构。
- 图片算法选择改为带图标、说明和选中状态的卡片式界面。
- Windows 使用居中双列弹窗，Android 使用单列可滚动底部面板。
- Android 延续 `com.langbai.imagescrambler` 包名和同一正式签名证书，可覆盖安装 v1.0.0。

## 下载

- Windows 安装版：`Langbai-Image-Scrambler-Setup-v1.0.1.exe`
- Android：`Langbai-Image-Scrambler-v1.0.1-android.apk`
- Windows 免安装版：`Langbai-Image-Scrambler-v1.0.1-windows-portable.zip`
- 校验文件：`SHA256SUMS.txt`

Windows 安装器当前未使用商业 Authenticode 证书。Android APK 使用与 v1.0.0 相同的固定发布证书签名。
