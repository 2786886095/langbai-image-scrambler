# Langbai 图片混淆 v1.1.0

本版本重点提升批量处理速度和导出安全性，并加入多文件夹任务、撤回记录与配置持久化。

## 新增与改进

- 图片批量处理改为工作者并发队列。
- 默认自动选择并发数且最多同时处理 4 张，也可手动选择 1、2、4、8。
- 可连续加入多个文件夹；Windows 支持一次拖入多个文件夹。
- 待处理列表按文件夹分组并默认折叠，点击后查看内部文件。
- 图片输出保持原文件基础名，仍统一输出无损 PNG。
- 同名文件和文件夹使用 `（1）`、`（2）` 持续递增，不覆盖已有内容。
- 新增导出与撤回记录，可撤回任意尚在保留期内的批次。
- 撤回前校验 SHA-256，只删除未修改的输出；已修改文件会保留并计入跳过数量。
- 历史默认保留 7 天，可设置 1、7、30、90 天或永久保留；清理历史不会删除输出。
- 工作区、模式、算法、密码保护开关、并发数和导出偏好支持重启恢复。
- 密码内容、手动种子和待处理文件列表不会持久化。
- Android 延续相同包名与发布证书，可覆盖安装 v1.0.0/v1.0.1。

## 下载

- Windows 安装版：`Langbai-Image-Scrambler-Setup-v1.1.0.exe`
- Android：`Langbai-Image-Scrambler-v1.1.0-android.apk`
- Windows 免安装版：`Langbai-Image-Scrambler-v1.1.0-windows-portable.zip`
- 校验文件：`SHA256SUMS.txt`

Windows 安装器当前未使用商业 Authenticode 证书。Android APK 使用既有固定发布证书签名。
