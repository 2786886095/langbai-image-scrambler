# Langbai 图片混淆 v1.2.1

## 新功能与修复

- 小说 TXT 工作区新增剪贴板 Base64：粘贴 UTF-8 原文或 Base64，处理后可一键复制完整结果。
- TXT 文件导入继续按原始字节批量转码/恢复，不改变 UTF-8、GBK、UTF-16、换行符或其他字节内容。
- 自动还原完成后新增“打开输出位置”；任务列表可打开单个结果，导出历史的每一项也可定位输出。
- Windows 在资源管理器中定位结果；Android 优先进入导出文件夹，单文件直接打开结果文件。
- 修复 ZIP 中文文件名乱码：新 ZIP 明确写入 UTF-8 标记；Android 自动识别旧式 GBK/CP936 名称；Windows 使用内置 7-Zip 处理 ZIP、7Z、RAR 和密码。
- ZIP、7Z、RAR 导入继续保留内部目录结构、原文件夹名与同名递增规则。

## 下载

- Windows 安装版：`Langbai-Image-Scrambler-Setup-v1.2.1.exe`
- Android：`Langbai-Image-Scrambler-v1.2.1-android.apk`
- Windows 免安装版：`Langbai-Image-Scrambler-v1.2.1-windows-portable.zip`
- 校验文件：`SHA256SUMS.txt`

Android 包继续使用 `com.langbai.imagescrambler`、`versionCode 5` 和原正式签名，可覆盖升级此前公开版本。
