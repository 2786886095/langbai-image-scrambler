# Langbai 图片混淆 v1.2.3

本版本修复压缩输出的路径选择与重复处理问题，并加入 Windows、Android 软件内更新。

## 修复

- 开启“每次询问导出位置”与“压缩输出”时，在耗时处理前选择目标路径。
- 导出写入取消或失败后保留本次已生成压缩包，主按钮显示“继续导出”，重试时不会再次混淆或转码。
- Android 单压缩包同样先使用系统文档选择器确定目标。

## 软件内更新

- 用户点击“立即更新”后才开始下载，不后台自动下载。
- 下载完成后强制校验 GitHub Release 的 SHA-256。
- Windows 退出当前进程、静默覆盖安装并自动重新启动。
- Android 打开系统 APK 安装确认；继续复用固定包名、正式签名和递增的 `versionCode 7`。
- 设置页加入 GitHub 项目主页按钮。

## 安装包

- Windows 安装版：`Langbai-Image-Scrambler-Setup-v1.2.3.exe`
- Android：`Langbai-Image-Scrambler-v1.2.3-android.apk`
- Windows 免安装版：`Langbai-Image-Scrambler-v1.2.3-windows-portable.zip`
