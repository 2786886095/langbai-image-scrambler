# Langbai 图片混淆 v1.0.0

首个公开版本，提供 Windows 与 Android 双端离线批量图片混淆/还原。

## 主要功能

- 七种可逆算法及小番茄 Gilbert 曲线兼容模式
- 本软件 PNG 自动识别算法与像素 SHA-256 完整性校验
- PBKDF2-HMAC-SHA256 + AES-256-GCM 可选密码保护
- 多图、文件夹递归、子目录结构保留
- 单图单文件、多图批次文件夹、固定路径或每次询问
- Android 8.0+ Storage Access Framework 目录处理
- 简体中文、繁体中文、深浅主题和 GitHub Releases 更新提示

## 下载

- Windows：`Langbai-Image-Scrambler-Setup-v1.0.0.exe`
- Android：`Langbai-Image-Scrambler-v1.0.0-android.apk`
- Windows 免安装：`Langbai-Image-Scrambler-v1.0.0-windows-portable.zip`

Windows 安装器当前未使用商业 Authenticode 证书。Android APK 使用固定发布证书签名，后续版本将复用同一签名以支持覆盖更新。
